## FRP内网穿透完全指南

#### 为什么写这篇

1. 很多开发者都有这样的需求：在外面想访问家里的NAS、远程桌面、开发服务器，但家庭网络没有公网IP
2. FRP（Fast Reverse Proxy）是目前最流行的内网穿透工具之一，开源、高性能、配置简单
3. 本文从零开始，手把手教你搭建FRP，覆盖常见使用场景

#### 什么是内网穿透？

简单来说，内网穿透就是让外网能够访问到内网中的服务。

正常情况下，家里的电脑、NAS等设备处于路由器NAT后面，外网无法直接访问。内网穿透通过一台有公网IP的服务器做中转，把外网请求转发到内网设备上。

```
外网用户 ──► 公网服务器(frps) ◄── 隧道 ──► 内网设备(frpc) ──► 本地服务
```

#### FRP架构

FRP分为两个组件：

| 组件 | 部署位置 | 作用 |
| --- | --- | --- |
| **frps**（服务端） | 有公网IP的服务器（如VPS） | 接收外网请求，转发给客户端 |
| **frpc**（客户端） | 内网设备（家里的电脑/NAS） | 主动连接服务端，建立隧道 |

#### 前置条件

- 一台有公网IP的服务器（阿里云、腾讯云、Vultr等VPS均可）
- 内网设备（你要穿透的机器）
- 服务器开放相应端口（安全组/防火墙）

#### 第一步：下载FRP

前往 [FRP GitHub Releases](https://github.com/fatedier/frp/releases) 下载最新版本。

**服务端（Linux VPS）：**

```bash
# 下载（以v0.61.1为例，请替换为最新版本）
wget https://github.com/fatedier/frp/releases/download/v0.61.1/frp_0.61.1_linux_amd64.tar.gz

# 解压
tar -zxvf frp_0.61.1_linux_amd64.tar.gz
cd frp_0.61.1_linux_amd64
```

**客户端（Windows）：**

下载对应的 `frp_x.x.x_windows_amd64.zip`，解压即可。

**客户端（Linux）：**

```bash
wget https://github.com/fatedier/frp/releases/download/v0.61.1/frp_0.61.1_linux_amd64.tar.gz
tar -zxvf frp_0.61.1_linux_amd64.tar.gz
cd frp_0.61.1_linux_amd64
```

#### 第二步：配置服务端（frps）

编辑 `frps.toml`：

```toml
# frps.toml - 服务端配置
bindPort = 7000           # frp服务端监听端口，客户端连接用
auth.method = "token"
auth.token = "your_secure_token_here"  # 认证Token，客户端需要一致

# Web管理面板（可选）
webServer.addr = "0.0.0.0"
webServer.port = 7500
webServer.user = "admin"
webServer.password = "admin123"
```

启动服务端：

```bash
./frps -c frps.toml
```

#### 第三步：配置客户端（frpc）

编辑 `frpc.toml`：

```toml
# frpc.toml - 客户端配置
serverAddr = "your_vps_ip"   # 你的VPS公网IP
serverPort = 7000             # 与服务端bindPort一致
auth.method = "token"
auth.token = "your_secure_token_here"  # 与服务端一致
```

#### 常见场景配置

##### 场景一：SSH远程访问内网Linux

在 `frpc.toml` 中添加：

```toml
[[proxies]]
name = "ssh"
type = "tcp"
localIP = "127.0.0.1"
localPort = 22
remotePort = 6022    # VPS上暴露的端口
```

使用方式：

```bash
ssh -p 6022 user@your_vps_ip
```

##### 场景二：远程桌面（Windows RDP）

```toml
[[proxies]]
name = "rdp"
type = "tcp"
localIP = "127.0.0.1"
localPort = 3389
remotePort = 3389
```

使用方式：打开远程桌面连接，输入 `your_vps_ip:3389`。

##### 场景三：Web服务穿透

```toml
[[proxies]]
name = "web"
type = "tcp"
localIP = "127.0.0.1"
localPort = 8080       # 本地Web服务端口
remotePort = 8080      # VPS暴露端口
```

访问 `http://your_vps_ip:8080` 即可。

##### 场景四：HTTP域名穿透

如果你有域名，可以用HTTP类型代理实现多个Web服务共用80端口：

服务端 `frps.toml` 增加：

```toml
vhostHTTPPort = 80
vhostHTTPSPort = 443
```

客户端 `frpc.toml`：

```toml
[[proxies]]
name = "web-site"
type = "http"
localPort = 8080
customDomains = ["dev.yourdomain.com"]

[[proxies]]
name = "nas-web"
type = "http"
localPort = 5000
customDomains = ["nas.yourdomain.com"]
```

将域名 `dev.yourdomain.com` 和 `nas.yourdomain.com` 的A记录指向VPS IP即可。

##### 场景五：NAS穿透

```toml
# 群晖NAS管理界面
[[proxies]]
name = "nas-dsm"
type = "tcp"
localIP = "192.168.1.100"    # NAS的内网IP
localPort = 5000
remotePort = 5000

# NAS文件服务
[[proxies]]
name = "nas-file"
type = "tcp"
localIP = "192.168.1.100"
localPort = 445
remotePort = 4450
```

#### 第四步：设置开机自启

##### Linux服务端/客户端（Systemd）

创建服务文件 `/etc/systemd/system/frps.service`（服务端）：

```ini
[Unit]
Description=FRP Server Service
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/frp/frps -c /usr/local/frp/frps.toml
Restart=on-failure
RestartSec=5s

[Install]
WantedBy=multi-user.target
```

客户端同理，把 `frps` 改成 `frpc`。

```bash
# 启用并启动
sudo systemctl daemon-reload
sudo systemctl enable frps
sudo systemctl start frps

# 查看状态
sudo systemctl status frps
```

##### Windows客户端

使用 `WinSW` 或直接用任务计划程序：

1. 打开"任务计划程序"
2. 创建基本任务，触发器选"计算机启动时"
3. 操作选"启动程序"，指向 `frpc.exe -c frpc.toml`

#### 安全加固

FRP暴露了内网服务到公网，安全措施必不可少：

##### 1. 使用强Token

```toml
# 不要用简单密码！
auth.token = "a1b2c3d4e5f6g7h8_MySecureToken_2026"
```

##### 2. 开启TLS加密

服务端：

```toml
transport.tls.force = true
```

客户端：

```toml
transport.tls.enable = true
```

##### 3. 限制端口范围

服务端限制客户端能使用的端口：

```toml
allowPorts = [
  { start = 6000, end = 7000 },
  { single = 8080 },
  { single = 8443 }
]
```

##### 4. 配合防火墙

```bash
# 只开放需要的端口
sudo ufw allow 7000/tcp    # frp通信端口
sudo ufw allow 6022/tcp    # SSH穿透端口
sudo ufw allow 8080/tcp    # Web穿透端口
```

##### 5. 限制带宽

```toml
[[proxies]]
name = "ssh"
type = "tcp"
localIP = "127.0.0.1"
localPort = 22
remotePort = 6022
transport.bandwidthLimit = "1MB"    # 限制带宽
```

#### Dashboard监控

frps的Web面板可以实时查看：

- 当前连接的客户端
- 各代理的流量统计
- 在线状态

访问 `http://your_vps_ip:7500`，输入配置的用户名密码即可。

**服务端 frps.toml：**

```toml

vhostHTTPPort = 80
vhostHTTPSPort = 443

  { start = 6000, end = 9000 }
```

**客户端 frpc.toml：**

```toml
serverAddr = "1.2.3.4"
```

#### 常见问题

##### Q: 连接不上怎么办？

1. 检查VPS安全组/防火墙是否放行端口
2. 检查Token是否一致
3. 检查serverAddr是否正确
4. 查看frps/frpc日志排查错误

##### Q: 延迟很高？

- 选择离你近的VPS机房
- 检查VPS带宽是否足够
- 考虑使用QUIC协议（frp支持KCP/QUIC）

##### Q: 和其他方案对比？

| 工具 | 优势 | 劣势 |
| --- | --- | --- |
| **FRP** | 开源、功能全、性能好 | 需要自备VPS |
| **ngrok** | 无需VPS、即开即用 | 免费版限制多 |
| **Tailscale** | P2P直连、零配置 | 依赖第三方服务 |
| **ZeroTier** | 组建虚拟局域网 | 适合内网互联，不擅长端口暴露 |

#### 总结

FRP是一个强大且灵活的内网穿透工具，核心要点：

1. **架构简单**：服务端frps + 客户端frpc，通过Token认证
2. **场景丰富**：TCP/UDP/HTTP/HTTPS全支持，几乎覆盖所有穿透需求
3. **安全第一**：务必开启TLS、使用强Token、配合防火墙
4. **开机自启**：生产环境一定要配置Systemd或任务计划

有了FRP，你的内网设备就像拥有了公网IP一样自由！
